🇮🇹 Italiano

Memoria Giapponese è una Progressive Web App (PWA) personale progettata per aiutare nello studio e nel richiamo del vocabolario giapponese.

L'applicazione nasce dall'esigenza di avere uno strumento più flessibile di un semplice dizionario: non si limita a mostrare una traduzione, ma permette di ricercare e richiamare le parole giapponesi già studiate, insieme ai relativi significati e sinonimi.

✨ Caratteristiche
Ricerca di vocaboli giapponesi a partire dall'italiano.
Ricerca all'interno delle parole e delle espressioni già memorizzate.
Supporto alla traduzione di frasi italiane attraverso il vocabolario personale.
Possibilità di associare più traduzioni e sinonimi allo stesso termine.
Gestione di espressioni idiomatiche come unità linguistiche autonome.
Interfaccia progettata per essere semplice e adatta all'uso quotidiano.
Funzionamento come Progressive Web App (PWA).
Possibilità di installare l'app sul dispositivo come una normale applicazione.
Funzionamento offline tramite Service Worker, ove previsto dalla configurazione dell'app.
📚 Origine del vocabolario

Il vocabolario è pensato per raccogliere le parole e le espressioni giapponesi già studiate dall'utente.

Una parte importante del progetto è costituita dal vocabolario acquisito attraverso lo studio personale e, in particolare, attraverso WaniKani.

L'obiettivo non è sostituire un dizionario giapponese tradizionale, ma creare una memoria lessicale personale, orientata soprattutto al recupero delle parole durante la costruzione di frasi.

🔎 Ricerca contestuale

Una delle funzioni centrali del progetto consiste nella possibilità di inserire una frase italiana anziché una singola parola.

L'applicazione può quindi individuare i termini presenti nel proprio vocabolario e mostrare le corrispondenti traduzioni giapponesi.

Questo approccio è pensato per aiutare soprattutto quando si conosce già una parola giapponese, ma non la si riesce a ricordare spontaneamente mentre si sta cercando di formulare una frase.

💬 Espressioni idiomatiche

Le espressioni idiomatiche possono essere memorizzate come singole unità linguistiche, invece di essere necessariamente suddivise nelle singole parole che le compongono.

In questo modo il sistema può distinguere, quando necessario, tra:

traduzione letterale dei singoli elementi;
significato dell'espressione nel suo complesso.

Memoria Giapponese 5.0

Il progetto può essere pubblicato tramite GitHub Pages e utilizzato direttamente dal browser.

📲 Installazione

Memoria Giapponese 5.0 può essere installata come applicazione tramite un browser compatibile con le Progressive Web App.

💻 Windows / PC
Aprire l'indirizzo web dell'applicazione con Google Chrome o Microsoft Edge.
Attendere il caricamento completo della pagina.
Utilizzare l'icona Installa nella barra degli indirizzi, se disponibile.
Confermare l'installazione.
L'applicazione verrà aggiunta alle applicazioni del computer e potrà essere avviata separatamente dal browser.

In alternativa, con Chrome o Edge è possibile utilizzare il menu del browser e cercare l'opzione Installa Memoria Giapponese o Installa app.

📱 Android
Aprire l'indirizzo dell'applicazione con Google Chrome.
Aprire il menu del browser ⋮.
Selezionare Installa app oppure Aggiungi alla schermata Home, a seconda della versione del browser.
Confermare l'installazione.

L'icona di Memoria Giapponese verrà quindi aggiunta alla schermata Home e l'app potrà essere avviata come un'applicazione.

🍎 iPhone / iPad
Aprire l'applicazione con Safari.
Toccare il pulsante Condividi.
Selezionare Aggiungi alla schermata Home.
Confermare con Aggiungi.

L'applicazione verrà aggiunta alla schermata Home e potrà essere aperta separatamente da Safari.

Nota: le opzioni di installazione possono variare leggermente a seconda del browser, del sistema operativo e della versione utilizzata.

🇬🇧 English

Memoria Giapponese is a personal Progressive Web App (PWA) designed to support the study and recall of Japanese vocabulary.

The application was created to provide a more flexible tool than a traditional dictionary. Rather than simply displaying a translation, it allows users to search for and retrieve Japanese words they have already studied, together with their meanings and synonyms.

✨ Features
Search for Japanese vocabulary starting from Italian.
Search within previously memorized words and expressions.
Support for translating Italian sentences using the user's personal vocabulary.
Multiple translations and synonyms can be associated with the same term.
Idiomatic expressions can be stored as independent linguistic units.
A simple interface designed for everyday use.
Progressive Web App (PWA) functionality.
Installation on compatible devices as a regular application.
Offline functionality through a Service Worker, where supported by the app configuration.
📚 Vocabulary

The vocabulary is designed to contain Japanese words and expressions that the user has already studied.

An important part of the project consists of vocabulary acquired through personal study, particularly through WaniKani.

The purpose of the application is not to replace a traditional Japanese dictionary, but to provide a personal lexical memory focused on recalling words while constructing sentences.

🔎 Contextual Search

One of the main features of the project is the ability to enter an entire Italian sentence rather than just a single word.

The application can identify terms contained in its personal vocabulary and display their corresponding Japanese translations.

This approach is particularly useful when the user already knows a Japanese word but cannot spontaneously recall it while trying to formulate a sentence.

💬 Idiomatic Expressions

Idiomatic expressions can be stored as single linguistic units, rather than necessarily being divided into their individual components.

This allows the system to distinguish, when necessary, between:

the literal translation of individual elements;
the meaning of the expression as a whole.

📲 Installation

Memoria Giapponese 5.0 can be installed as an application using a browser that supports Progressive Web Apps.

💻 Windows / PC
Open the application's web address using Google Chrome or Microsoft Edge.
Wait for the page to load completely.
Use the Install icon in the address bar, if available.
Confirm the installation.
The application will be added to the computer's applications and can be launched separately from the browser.

Alternatively, in Chrome or Edge, open the browser menu and look for Install Memoria Giapponese or Install app.

📱 Android
Open the application using Google Chrome.
Open the browser menu ⋮.
Select Install app or Add to Home screen, depending on the browser version.
Confirm the installation.

The Memoria Giapponese icon will be added to the Home screen and the application can then be launched like a regular app.

🍎 iPhone / iPad
Open the application using Safari.
Tap the Share button.
Select Add to Home Screen.
Confirm by tapping Add.

The application will be added to the Home screen and can be opened separately from Safari.

Note: installation options may vary slightly depending on the browser, operating system, and version being used.
