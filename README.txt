MEMORIA GIAPPONESE — PACCHETTO PWA DEFINITIVO

Contenuto:
- index.html              applicazione principale
- manifest.json           configurazione PWA
- service-worker.js       supporto offline/cache
- icon-192.png            icona app
- icon-512.png            icona app ad alta risoluzione
- icon-512-opaque.png     variante per installazione maskable

Uso locale:
- index.html può essere aperto direttamente nel browser.

Pubblicazione PWA:
- Per installare la PWA e usare il service worker è necessario pubblicare
  la cartella tramite HTTPS oppure eseguirla su localhost.
- Il pacchetto è pronto per GitHub Pages, Netlify o un altro hosting statico.

Dati:
- L'archivio del vocabolario resta nel browser dell'utente (localStorage).
- Il sito non contiene il tuo archivio personale.
- Usa la funzione Esporta dell'app per creare una copia JSON di backup.

ENGLISH VERSION

MEMORIA GIAPPONESE — DEFINITIVE PWA PACKAGE

Contents:
- index.html              main application
- manifest.json           PWA configuration
- service-worker.js       offline/cache support
- icon-192.png            app icon
- icon-512.png            high-resolution app icon
- icon-512-opaque.png     maskable installation variant

Local use:
- index.html can be opened directly in a web browser.

PWA publication:
- To install the PWA and use the service worker, the folder must be
  published over HTTPS or served from localhost.
- The package is ready for GitHub Pages, Netlify, or another static host.

Data:
- The vocabulary archive remains in the user's browser (localStorage).
- The website does not contain your personal vocabulary archive.
- Use the app's Export function to create a JSON backup copy.
